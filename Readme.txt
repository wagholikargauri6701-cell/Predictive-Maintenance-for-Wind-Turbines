# Project: Wind Turbine Data Analysis and Anomaly Detection

This repository contains the work and analysis done on the Wind B dataset, focusing on anomaly detection using clustering algorithms and change point detection techniques. Below is an overview of the folder structure and the contents of each section.

## Folder Structure

### 1) Dataset
The `Dataset` folder contains the raw Wind B dataset used for the analysis and anomaly detection tasks. All dataset-related files are stored here.

### 2) Notebooks
The `Notebooks` folder contains separate Jupyter notebooks for both team members. These notebooks are used for:
- Data Preprocessing
- Clustering (K-Means)
- Change Point Detection (PELT)

Each team member has their notebook to handle different aspects of the analysis.

### 3) Report
The `Report` folder contains the detailed scientific report documenting the methodology, results, and conclusions drawn from the project. This section includes all textual analysis, visualizations, and explanations of the work done.

### 4) Declaration PDF
The `Declaration` folder includes the PDF document with the formal declaration for the project, outlining the individual contributions and acknowledgements.

## Project Overview
This project focuses on detecting anomalies in the Wind B dataset using machine learning and statistical methods, including:
- WP1 (Data Analysis): Preprocessing, feature extraction, and visualization of the dataset.
- WP2 (Clustering): Using k-means clustering to identify normal and anomalous patterns in the data.
- WP3 (Change Point Detection): Detecting state changes using dynamic programming-based PELT algorithm.

For detailed explanations of each work package, please refer to the notebooks and the report section.
